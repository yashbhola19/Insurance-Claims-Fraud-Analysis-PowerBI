# Insurance Claims & Fraud Analysis – Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze insurance claims, identify fraud patterns, and generate meaningful business insights.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Key Findings
- Total Claims: 1,000
- Fraudulent Claims: 247
- Fraud Rate: 24.7%
- January recorded the highest claim volume.
- Policy coverage 100/300 had the highest total claim amount.

## Key Features
- Interactive KPI cards
- Monthly claim analysis
- Fraud detection analysis
- Policy coverage comparison
- Interactive slicers and filters
- Business insights and recommendations

## Objective
To transform insurance data into actionable insights using data visualization and business intelligence techniques.
